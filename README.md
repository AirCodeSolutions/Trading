# Trading

Application de trading intraday conçue autour des timeframes **M5** et **M15**.

## Principes

- Backend Python / FastAPI.
- Frontend React / TypeScript.
- Séparation stricte entre données de marché, signaux, risque, exécution et reporting.
- Mode paper/demo par défaut.
- Aucun ordre live sans activation explicite et contrôles de risque.
- Stratégies évaluées en broker-net après coûts.

Le projet est en cours d'initialisation.
